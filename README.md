# 📊 Multi-Country Operations Dashboard

## Overview

This project demonstrates the development of a Power BI dashboard for monitoring operational performance across multiple countries.

## 🌍 Countries Covered

- Kenya
- Uganda
- Tanzania
- Zambia

## 📈 Key Performance Indicators

- Turnaround Time (TAT)
- Cases Handled
- Revenue Performance
- Conversion Rates
- Country Performance Comparison

- ## Professional Context

This project is inspired by operational reporting and dashboard development work supporting management visibility across Kenya, Uganda, Tanzania and Zambia.

Key areas monitored:

- Valuation Turnaround Time (TAT)
- Auction Performance
- Repossession Activity
- Service Delivery Metrics
- Operational KPI Tracking

The objective was to provide management with real-time visibility into performance trends and operational efficiency.

## 🛠 Tools Used

- Power BI
- Power Query
- DAX
- SQL
- Microsoft Excel

## 💡 Business Objective

Provide management with a consolidated view of operational performance and identify areas requiring intervention.
